
 # Gurgaon Real Estate Market Analysis

Exploratory data analysis of Gurgaon property listings using Python. The script cleans the data and answers 10 questions about pricing, localities, builders, and RERA approval.

## Tech Stack
Python, pandas, matplotlib, seaborn

## Files
- `data.csv` – property listings dataset
- `main.py` – data cleaning and analysis

## Analysis Covers
- Costliest flat
- Localities with the highest average price and rate per sq. ft.
- Ready-to-move vs under-construction pricing
- Effect of RERA approval on price
- Most expensive BHK configuration and property type
- Average price by builder
- Area vs rate per sq. ft. (scatter plot)
